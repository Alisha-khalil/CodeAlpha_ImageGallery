
# Image Gallery Project

A responsive image gallery built using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## About The Project

This project allows users to browse images in a responsive gallery. Users can click on an image to view it in a lightbox and navigate through images using Next and Previous buttons.

## Features

- Responsive image gallery
- Lightbox image preview
- Next and Previous navigation
- Close button functionality
- Smooth transitions and hover effects
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
